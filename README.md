## 🎮 Features

1. **Dual Mode Architecture:**
   - **🎮 Game Mode:** Interactive 2D retro world map where Shahadat transitions from on foot to motorcycle and skateboard across 7 thematic checkpoints with parallax cyberpunk skyline, animated pixel sprites, and 8-bit chiptune sound effects.
   - **📄 Recruiter Mode:** High-contrast, clean dark-mode executive portfolio with rapid-scan metrics, verified achievements, direct CV download, and copyable contact chips.
   - **Keyboard Quick Toggle:** Press `M` anytime to switch modes seamlessly.

2. **World Map Checkpoints:**
   - **Zone 1: Spawn Point:** Mission briefing, HUD stats, CGPA 3.91, 50% Merit scholarship, and motorcycle rev sound.
   - **Zone 2: The Telecom & Tech Hub:** Interactive building cards for Grameenphone (AdTech Product Intern), City Bank (IT Intern), and BRAC University (Teaching Assistant).
   - **Zone 3: Gulshan-2 Smart Intersection:** Interactive SUMO traffic simulator with Reinforcement Learning signal phasing and an interactive **"Inject Anomaly (Pothole + Jaywalker)"** stress test!
   - **Zone 4: The Arcade & Code Lab:** Retro arcade cabinet with 5 game cartridges mapped to verified GitHub repositories, plus full Agent Loadout skills matrix (excluding 3D printing per request).
   - **Zone 5: The Guild Hall:** 20x Blood Donor Honor Badge (with celebration confetti) and community leadership with Nissorgo Foundation and Project Srijon.
   - **Zone 6: Side Quests & Safe House:** Skateboard avatar transition, polaroid photo cards for motorcycle tours, skating, FPS gaming (*Valorant* & *Apex Legends*), and *Tin Goyenda* classic mystery lore.
   - **Zone 7: Extraction Point:** Encrypted transmission terminal contact form, quick-copy email & phone, and download CV.

3. **8-Bit Web Audio Engine:**
   - Synthesizes authentic retro square/triangle waves directly via the Web Audio API without needing external MP3s. Includes mute toggle with persistent storage.

- **To swap in your real bike / photography photos:** Place your images into `public/images/` and update the paths in `src/data/portfolioData.ts`.
- **To update your CV:** Replace `public/MD_Shahadat_Hossain_Main.pdf`.
